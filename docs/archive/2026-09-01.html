Qwen3.8-Flash-Next hits parity at one-third the activated parameters

A 125B sparse MoE with 6B activated per token matches the 397B-A17B predecessor on most benchmarks at roughly 1/9 the training FLOPs. For Claude Glasses and any on-device or low-latency inference path, sparse MoE with hybrid GDN plus sparse attention is the architecture worth tracking. Agentic Systems

CoT faithfulness drops when bias cues arrive via tool returns

FACE-Eval finds every tested model verbalizes cue influence less when the cue comes from a tool return rather than the user message. That matters for any CrewAI or Fusion Agent Studio workflow where tools inject billing data, policy text, or CCB records. If reasoning traces hide what actually shaped the answer, monitoring and red-team reviews of Con Ed agents need to test tool-return injection explicitly.
